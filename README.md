# Pixel Stats

Pixel Stats **1.0.0** is a LabyMod 4 addon for tracking the Pixel currency on
LabyWorld. It provides independent HUD widgets and a statistics dashboard in
German and English.

## Features

- Five independently configurable widgets: balance, earned today, this week's
  earnings, daily rent and apartment time remaining.
- Card appearance with configurable colors and width, or LabyMod's native text
  HUD with its standard formatting, scaling, labels and background settings.
- A dashboard with confirmed income, expenses and profit/loss for today, the
  current week and the complete recorded history.
- Line charts with point tooltips: 24 hourly intervals for today, Monday–Sunday
  for the week, and automatic daily, weekly, monthly or yearly grouping for the
  complete history.
- Automatic rent detection from the player's own rental menu and a saved
  apartment deadline from the player's own sign. The timer continues offline,
  omits minutes and warns below 24 hours.
- Separate local histories for each Minecraft account.

## Getting started

Use LabyMod 4 and install `build/libs/pixel-stats-release.jar` in your instance's
`labymod-neo/addons` directory while the game is closed. On a standard Windows
installation this is `%APPDATA%\.minecraft\labymod-neo\addons`. Restart the client
after replacing the JAR. The intermediate module JARs are not installable addons.

Join LabyWorld, then add the desired widgets under **LabyMod → Widgets → Pixel Stats**.
Each widget has its own appearance and color settings. The addon can be disabled
in its settings, including through LabyMod's server-controlled disabling mechanism.

Press **F8** to open the dashboard. The key can be changed in the addon settings;
`/pixelstats dashboard` opens the same screen. The shortcut only operates during
normal gameplay, leaving chat and menu input to Minecraft.

For automatic rent detection, open your own apartment's rental menu and hover
over the rent-price item. For the remaining-time widget, right-click your own
apartment sign. Other tenants' signs and rental menus are ignored. A detected
renewal adds three days to the saved deadline; repeated rounded sign readings do
not restart the countdown. The displayed deadline remains an estimate.

## How accounting works

The Pixel balance in the sidebar scoreboard confirms balance changes. Only
positive observed changes increase income; negative changes count as expenses.
Profit/loss is income minus expenses. Rent is displayed separately and is not
subtracted a second time.

When a minigame hides the Pixel scoreboard, the last confirmed balance remains
available. Optional provisional chat credits are marked **≈** in the HUD and are
kept separate from confirmed history. The dashboard shows them as awaiting
verification. Generic `+amount Pixel` parsing supports different boost and event
messages without trusting their wording as proof of payment.

LabyMod's `SYSTEM` chat type also includes messages generated by local addons.
Sender checks and transfer-report filtering reject obvious unrelated messages;
only an actual scoreboard increase can confirm a candidate. On return to a stable
scoreboard, unmatched candidates are discarded and already-counted increases are
not counted twice. Restarting the client does not turn an estimate into income.

Statistics cover observations made by the addon, not the account's entire server
transaction history. Simultaneous income and spending between observations can
only be recovered as a net change. Offline changes without an observed candidate
are not credited as new earnings. Dates use the computer's local timezone and
weeks begin on Monday.

Hourly detail is retained for the recent seven days, daily detail for the recent
90 days, and monthly and lifetime totals persist. Missing older detail is shown
as unavailable or earlier records; it is not assigned invented timestamps.

## Commands

The command prefix is `/pixelstats`; `/pstats` is an alias.

| Command | Action |
| --- | --- |
| `dashboard` | Open the statistics dashboard |
| `status` | Show the current balance, rent and apartment estimate |
| `debug` | Display locally observed scoreboard, tooltip and apartment information |
| `rent <amount>` / `miete <amount>` | Set the rent for a three-day period manually |
| `auto` | Clear the manual rent override and resume automatic detection |
| `resetincome <today\|week\|all>` | Clear income and net history for the chosen period |

Resetting income keeps the balance, rent and apartment data. German command
aliases are also accepted. Every consumed command produces a local reply.

## Local data and privacy

Account histories are stored as UTF-8 properties files under
`<game directory>/labymod-neo/addons/pixelstats/data/<account UUID>.properties`.
They contain the confirmed balance, period totals, provisional credits, rent and
owned apartment estimate. The UUID separates accounts; the tenant name validates
the player's own sign. The addon has no telemetry, remote database or external
network requests.

Writes use a temporary file in the same directory and atomic replacement where
supported. Malformed or unsupported newer files are preserved; automatic writes
for that account are suspended after a failed load. Internal file-format and
configuration-schema versions are independent of the public addon version.

## Building

Use the included Gradle wrapper with JDK 25, as in the official LabyMod CI
workflow. Production Java classes target Java 21.

```sh
./gradlew build createReleaseJar
```

On Windows, use `gradlew.bat`. The installable result is
`build/libs/pixel-stats-release.jar`. The `VERSION` environment variable may set
the release version; the default is `1.0.0`.

The GitHub Actions workflow builds the addon and uploads the release JAR as the
**Artifacts** workflow artifact. Only production sources and the files required
to build and review the addon are included in this repository.

Runtime code is in `core/src/main`. The `api` module and generated `game-runner`
retain the official LabyMod template structure. Generated resource indices,
build output and local client files are ignored by Git.

Pixel Stats uses the public LabyMod 4 Addon API. Before submission, verify the
release JAR in a production client as described in the
[official publishing instructions](https://dev.labymod.net/pages/addon/publishing/publish/).
Pixel Stats is an independent addon and has not been approved for the LabyMod
addon store.
